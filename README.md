# Simple Twitter 🐦

A simple Twitter-inspired web application built with HTML, CSS, and JavaScript. This project demonstrates DOM manipulation, event handling, and interactive user interface development using the Browser Object Model (BOM).

## 🚀 Features

- **Add Tweets:** Create and display new tweets.
- **Edit Tweets:** Modify existing tweet content.
- **Liked Tweets:** Navigate to a dedicated view for liked tweets.
- **Interactive Navigation:** Switch between the main tweet list and other views.
- **Alert Messages:** Display feedback messages to users.
- **Simple Interface:** Clean layout with easy-to-use buttons and text input.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Document Object Model (DOM)
- Browser Object Model (BOM)

## ⚙️ Getting Started

### Prerequisites

A modern web browser and a code editor such as Visual Studio Code.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/aashishraj0/Twitter-Clone-Web-App
   ```

2. Navigate to the project folder:

   ```bash
   cd simple-twitter
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
